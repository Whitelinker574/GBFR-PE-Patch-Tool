# v2.0.13｜按技能配装现在会一起计算整套装备

本版本重点修正“按技能目标配装”的来源范围和真实写入结果。用户照着游戏面板填写技能等级时，工具不再只看 12 个因子槽，而会把当前武器、武器祝福、四个召唤石、专精和因子带来的同名技能合并计算。

- 按技能目标配装支持任意数量的目标，并继续按用户排列顺序满足；
- 求解器会优先复用当前背包实例，同时评估武器、武器祝福、召唤石和专精已经提供的等级，避免重复堆叠；
- 需要调整装备时，方案会明确列出武器、祝福与召唤石变化，应用后先回填配装草稿，不会直接写入存档；
- 角色专属因子会按合法主词条构造，不再为了凑组合被放到副词条；
- 修正“因子强化”造成的最终等级偏差，制造因子时会按目标面板等级反推存储等级；
- 补全 DLC 技能和武器专属技能的名称、效果曲线与来源归属，避免黑龙系列、浩劫新星等项目在结果中丢失或串名；
- 修正武器组合上限优先截掉后续阶段的问题，已遍历 162 组可超凡武器表，确认各武器自己的五槽技能都能进入优化器；巴哈姆特武器、觉醒武器与其他武器继续分别读取各自技能表，不会把“超凡奥秘”“伤害上限·轰天”等专属技能替换成通用模板；
- 单独核对全部 29 把巴哈姆特武器：满觉醒固有“因子强化”均按 Lv1 计算；觉醒武器和超凡重构候选使用各自阶段表，不与巴武等级混算；
- 使用真实 SaveData2 的临时副本完成菲迪埃尔 26 项技能目标回读，武器、祝福、四个召唤石与 12 个独立因子槽共同写入后逐项达到目标，原存档未被修改。

下载前请确认发布页文件名为 `v2.0.13`。离线写入仍会自动备份、原子替换并重新打开回读；建议在完全退出游戏后修改存档。
