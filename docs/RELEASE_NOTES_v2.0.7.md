# v2.0.7｜因子与祝福编辑不再被天然规则卡住

这一版统一修正了存档生成、即时编辑、配装编辑和虚拟因子制造中的词条与等级限制。天然掉落和效果曲线仍用于推荐默认值与风险提示，但不再替用户否决游戏字段能够保存的选择。

## 因子编辑

- 加入游戏 2.0.3 合成词条表，`坚持 V+ + 坚守`、双伤害上限等目录已知组合可以直接选择和写入；
- 非天然组合不再被自动清空，写入前会说明游戏可能按自身规则显示或替换；
- 因子等级、主词条等级和副词条等级可以手工超过天然值或效果曲线，默认值和一键推荐仍使用正常等级；
- 存档因子生成、游戏内即时编辑、配装构造/导入、分享配装导入和虚拟因子来源制造复用同一套可写池与校验。

## 祝福编辑

- 存档祝福生成、游戏内即时编辑和配装导入均允许手工输入超过效果曲线的等级；
- 效果曲线只作为提示和默认值，不再作为写入门禁；
- 未知词条、空的必填槽、重复词条和超出底层字段范围的值仍会被拒绝。

## 写入边界

所有离线写入继续执行备份、临时文件、原子替换和重新打开回读。即时编辑继续绑定当前进程与选中记录并在写入前复核地址。非天然组合可能被游戏自动替换，因此页面会提示用户写入后回到游戏核对实际显示。

## 验证结果

- Go 全仓测试通过；
- 前端 593 条测试中 592 通过，1 条外部归档条件测试跳过；
- 前端生产构建、包体预算、Windows Wails 生产构建、静态检查和仓库清洁检查通过。
