# v2.0.15｜2.0.3 怪物增强与召唤石技能补充

本次逐项核对原项目 v1.9.6 之后的 v1.9.7–v1.9.9 更新，只补入当前项目确实缺少的部分：

- 怪物多倍血、全队怪物伤害、昏厥条和 Overdrive 状态不再只依赖 2.0.2 固定地址。工具会在游戏 2.0.3 中用唯一特征定位，并继续校验原字节、写后回读、所有权标记和停用恢复；2.0.2 地址仅在原字节完整一致时作为回退。
- 新增“Overdrive 槽变化倍率”。`2` 表示 OD 槽积累与减少速度为两倍，`0.5` 表示一半，可与“自动 OD / 空条 / 满黄条”分开使用。
- 召唤石主技能列表补充“不动（非天然）”，支持表中确认的最高 Lv30。它不会伪装成天然掉落组合，界面会明确显示“非天然”；其他召唤石的天然主技能仍按各自解包词池校验。

原项目同期的召唤石换类型、药水数量、坐标/重力、祝福错误处理和队伍伤害记录等改动，在空域工坊现有版本中已经覆盖，因此没有重复移植旧实现。
