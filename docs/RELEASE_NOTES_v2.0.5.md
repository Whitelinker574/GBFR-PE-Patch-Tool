# v2.0.5｜补全游戏 2.0.3 实时适配

这一版修复 v2.0.4 过于保守的版本门禁。游戏 2.0.3 的实时入口不再被统一锁住，而是按每项功能自己的 EXE 身份、特征码、原字节和恢复路径分别校验。

## 2.0.3 实时功能

- 修复“无视召唤限制”和“MSP / 境界点数不减”在 2.0.3 上移动的补丁位置；
- 82 个运行时补丁站点在 2.0.2 与 2.0.3 EXE 中都完成唯一匹配核对；
- 游戏内因子、祝福石、召唤石、队友配装读取、角色面板、坐标与重力等共享读取路径使用对应版本布局；
- 显示精度、房间 ID、主线自由队长、伤害事件、镜头、音频和虚拟因子入口完成 2.0.3 安装、状态回读和恢复检查；
- 天然掉落与锻造的 `data.i` 部署接受精确匹配的 2.0.3 游戏身份，并继续使用事务日志、原子替换和恢复校验。

## 两个实验开关不再被隐藏

“普通任务等级同步”和“重镶返还原祝福石”现在可以在“显示与房间工具”中选择。应用不再在界面或配置读取时强制清零这两个选项。

这两项已经验证 Hook 安装、写后状态和停用恢复，但仍保留“实验”标识：普通任务类型覆盖、完整重镶交易、旧石消耗和背包增量还需要更多游戏内样本。开启后请核对任务等级和背包结果，F12 可以恢复本工具管理的 Hook。

## 稳定性与恢复

- 免费队长补丁更新为 2.0.2 / 2.0.3 双布局；
- 镜头辅助进程异常退出后，已验证自动恢复并释放所有权；
- QOL 全配置紧急停止已验证，游戏进程在测试后保持运行；
- 未识别的游戏 EXE、非唯一特征码、原字节冲突和恢复失败仍会停止写入并给出明确错误。

## 验证结果

- Go 全量测试通过；
- 前端 593 条测试中 592 通过，1 条外部归档条件测试跳过；
- `go vet -unsafeptr=false ./...` 与 `staticcheck -checks 'all,-ST1003,-ST1005' ./...` 通过；
- 前端生产构建、包体预算和 Windows Wails 生产构建通过；
- 新构建已在游戏 2.0.3 运行期间启动并保持响应。

自动化和生命周期测试不能代替所有任务、场景和角色的长期实机效果。未完成的伤害归属、全角色动作上限、天然掉落结果、虚拟因子跨场景、多 Hook 音频听感、noclip 与相机相对飞行等边界没有被包装成已完成。
