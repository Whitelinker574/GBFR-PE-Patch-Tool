# v2.0.21｜命运篇章完成判断与档案检查修正

- 修复补完命运篇章时，部分已完成的战斗记录仍被重复提交，并提示“只允许从 0 写入完成值 1”的问题。已有完成状态会保留，未完成记录可继续正常补完。
- 档案检查现在明确列出尚未覆盖的角色，包括菲迪埃尔；不再把未检查的档案显示成“状态正常”。
- 新增「导出档案排查记录」快捷入口，导出各战斗任务的原始状态、档案覆盖情况和相关字段，方便定位跳过剧情或战斗后未触发的解锁。导出不包含存档路径，也不会修改存档。

使用入口：**存档实验室 → 命运篇章写入**。

本次修复了 Issue #23 反馈的重复写入报错和漏检提示。菲迪埃尔对应档案的实际解锁写入仍未完成，问题继续跟进；有同样情况可使用新版导出排查记录并补充到该 issue。
