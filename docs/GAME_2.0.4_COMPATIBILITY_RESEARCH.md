# 游戏 Ver. 2.0.4 官方更新与兼容性边界

> 核查日期：2026-08-07
> 证据范围：仅使用 Cygames 官方站点及 Steam 官方公告/API；不以社区转述推断游戏文件变化。

## 结论

游戏 Ver. 2.0.4 于 **2026-08-07** 发布。官方本次只明确列出一项修复：达到 Fatebreaker 等级的玩家如果在格兰赛法号甲板保存，可能无法再次加载该存档；安装 2.0.4 后，已经受影响的存档也可以恢复加载。

这是一项明确的**存档加载逻辑修复**，但官方没有披露存档 schema、字段布局、校验、压缩或加密方式发生变化，也没有披露 EXE、数据表、联机协议或资源文件的具体差异。因此，公告本身不能证明现有运行时 Hook 或离线解析器已兼容 2.0.4；这些仍需以本机更新后的文件哈希、AOB 唯一性、原字节校验和真实存档回读为准。

## 对 2.0.4 适配工作的直接要求

1. 先记录更新后游戏 EXE 的大小、SHA256 和 Steam 构建身份，再验证所有运行时补丁；不得只改版本字符串后沿用 2.0.3 地址。
2. 对每个 Hook 重新执行唯一签名扫描、原始字节校验、写后回读、停用恢复及 PID/创建时间所有权测试。
3. 对解包数据进行 2.0.3→2.0.4 差分，重点检查存档版本元数据、场景/位置状态、角色等级阶段以及读取时使用的枚举或表索引。
4. 用复制存档验证至少两条路径：普通地点保存，以及 Fatebreaker 等级在格兰赛法号甲板保存后退出、重启和重新打开。
5. 在拿到 Switch 2 后续更新的独立证据前，不把 PC/PlayStation 的验证结果写成 Switch 2 已验证。

## 本机 PC 文件与运行时核查

本节是对官方公告之外的本机 Steam 安装进行的可重复核查，不代表其他平台已经验证。

| 证据 | 2.0.4 结果 |
| --- | --- |
| Steam 构建 | Build ID `24526690`；manifest `8470078793693525332` |
| 游戏 EXE | `123,512,288` bytes；SHA-256 `F827F3C13CAA90B290FAB2FE7E28165A80448FDE0A3F7A96D79DAC6B8343FF2A` |
| `data.i` | `13,510,144` bytes；SHA-256 `F7C4A2D3AE65B85CEC96EF3A77B8C3A370A9A02584C6A77DD7AF5C676B1511EE`，与已锁定的 2.0.3 文件逐字节一致 |
| 更新文件范围 | 本机安装中仅 EXE 的时间、大小和哈希发生变化；项目依赖的 `data.i` 静态表没有变化 |
| 运行时目录 | 60 个功能、83 个补丁站点全部在 2.0.4 EXE 中唯一定位；54 个功能无需改变签名，4 个站点需要新的原字节，2 个站点继续使用 2.0.3 的签名变体 |
| 内置 `patch_core.dll` | 源码中的 36 条原生签名在 2.0.4 EXE 中全部唯一命中；虚拟因子、武器、怪物、镜头和 QOL 所需的版本布局已增加 2.0.4 分支 |
| 目录外运行时边界 | 任务结算倍率的长掩码签名在 `0x1FDB960` 唯一命中并解析到管理器槽 `0x7034CE0`；极沌空域计时器通过跨版本构造函数指令片段唯一映射到新全局 `0x7C22078`，未套用统一偏移 |

2.0.4 的代码变化不是统一地址平移：早期部分入口未移动，许多后段代码约移动 `+0xFA0`，若干全局数据约移动 `+0x1280`，也有 RIP 相对位移单独变化。因此适配采用按功能记录的 RVA、签名与原字节，不使用“给所有 2.0.3 地址统一加偏移”的做法。

当前已能证明的是：2.0.4 文件身份、静态表一致性、AOB 唯一性、原字节和构建链路。尚未在本轮取得运行中的 2.0.4 游戏进程，因此任务结算效果、保存后退出重开、场景切换以及多 Hook 长时间共存仍属于现场验收边界。
