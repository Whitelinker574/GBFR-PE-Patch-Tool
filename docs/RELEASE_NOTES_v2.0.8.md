# v2.0.8｜所有任务的普通物品奖励可以独立翻倍

这一版把“指定掉落清单”和“任务结算倍率”拆成两套互不依赖的功能。想让任务素材整体增加时，只需连接游戏并选择倍率，不必逐个添加物品。

## 全任务结算倍率

- 在“掉落与锻造规则”页顶部连接正在运行的游戏，可选择 `1× / 2× / 4× / 8× / 16×`；
- 普通任务、首领任务、任务宝箱和支线目标最终汇总到结算页的普通可堆叠物品使用同一倍率；
- 开关只作用于任务结算，商店购买、锻造消耗和手工物品编辑保持游戏原值；
- 单项最终数量封顶 999；断开游戏、关闭页面或退出应用时恢复原始入口与 `1×`；
- 因子、祝福石、召唤石和武器是带独立实例的奖励，不盲目复制同一个实例，保持原数量。

## 指定掉落清单

- 因子、祝福石、召唤石和普通物品都加入同一份待部署清单，不再先选“混合/只出某类”模式；
- 自选普通物品加入后，可在清单里直接填写每次抽中的最终数量（`1–999`），不再额外套一层倍率；
- 全任务倍率处理运行中的任务结算；指定清单只写入用户选择的游戏表记录，两边各管各的，不会互相相乘。

## 安全与验证

- 修复游戏 2.0.3 中“素材不消耗 / 设置背包物品数量”共享入口迁移后的兼容问题，同时保留 2.0.2 支持；
- 实时开关绑定完整游戏进程身份和页面所有权，安装前校验可执行文件、唯一签名与原字节；
- 代码洞和入口写入后均立即回读；停用、断开和应用退出会恢复原入口；
- 已在游戏 2.0.3 进程中完成 `2×` 安装、状态回读和 14 字节原入口恢复，游戏进程保持运行；
- 普通任务、首领任务、任务宝箱和支线目标的实际结算数量仍需要玩家在不同任务中继续验收，因此页面保留“实时任务结算”边界，不把实例奖励描述成已翻倍。
