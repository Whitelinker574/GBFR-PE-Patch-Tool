# v2.0.24｜修复“不动 V+”副词条编辑

- 补回游戏原表已有、编辑目录遗漏的“不动 V+”，现在可以选择副词条；原有“不动 V”继续保持单槽。
- 支持选择合成表中的“天星之雪”等副词条；超出天然掉落池的组合仍保留合规提示。
- 新增原表核对、前后端目录一致性、合法组合及非法副词条回归测试。
- 保留自动备份、写入前校验、回读验证与其他存档安全保护。

兼容游戏 2.0.6。本次修复通过 Windows 自动构建和测试；未进行游戏内实机验证。

更新后请重新启动工具。修改时选择“不动 V+”，即可打开副词条选项。
