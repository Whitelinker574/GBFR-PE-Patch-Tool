# v2.0.10｜当前武器技能、镜头预设与虚拟地面移动

这一版重点补齐游戏 2.0.3 下“选中对象后直接修改”和“实时功能长期保持”的使用流程，并重新整理了全屏与最小窗口布局。所有实时功能仍然默认关闭，只有主动开启后才常驻。

## 当前武器技能即时编辑

- 在游戏武器列表中高亮一把武器，工具会读取武器 ID、槽位、等级和五个永久技能槽；
- 修改五个永久槽时，先自动备份存档，再写入、保存并逐字节回读；武器等级、觉醒、祝福石和角色配装不会被顺带覆盖；
- 第六条及以后技能使用独立的运行时聚合路径，不会把数据越界写进下一把武器；可以逐条添加，切换页面后继续生效，直到手动关闭、按 F12、断开或退出；
- `0x02D0B733` 已按游戏内显示补全为“超凡技艺 / Unbound Technique”，中文、英文、图标搜索和回读列表使用同一条目录记录；
- 游戏仍可能规范化少见或冲突的组合，所以写入前会展示完整差异，写入后要求重新选择武器再继续编辑。

## 镜头与空间移动

- 城镇镜头新增“角色细节、游戏默认、舒适探索、战斗广角、远景观察”五档预设，并保留距离、高度和滚轮步进的手动微调；
- 坐标页把“虚拟地面移动”放到首要位置：WASD 使用游戏原生地面移动，PageUp / PageDown 调整虚拟地面的高度，F8 快速开关；
- 连续跳跃改为独立可展开功能，不再和虚拟地面混成一个开关；
- 空中动作模式仍保留在实验区，但重复攻击、闪避和跳跃后的动作状态尚不够稳定，不作为本版推荐玩法；
- 坐标读取、传送、书签和按轴微调集中到下方工具区，先让用户看到最常用的移动方式。

## 任务、召唤与养成便利

- 召唤持续时间支持 `0.1×–16×` 倍率或无限持续，使用同一套可恢复入口；
- 任务分数倍率只改变结算分数，不改变奖励物品数量；支线目标功能只补齐目标计数，奖励仍由游戏结算；
- 免费制作、交易与升级一次管理 11 条已核对的 2.0.3 消费路径，并与旧的单一素材扣减保护明确区分；
- 补丁目录扩展到 60 项，新增 Link Time 持续时间不减，并为闪避、格挡、宝箱、召唤、任务、MSP、CP、因子合成和刀上舞等项目补充了直接说明；
- 补丁按角色机制、战斗规则、任务流程和养成便利重新分组，全屏时利用横向空间，小窗口时自动改为单列。

## Logs 与运行状态

- Logs 战斗档案显示其合法性检测范围：十二个物理因子槽、祝福石、上限突破、召唤石和专精节点；武器自带技能与本工具运行时虚拟因子不在该规则输入中；
- 配装检测、虚拟因子、镜头、语音、额外武器技能和补丁仍通过顶部状态栏显示实际开启状态；默认不启动，也不会因为切换页面而中断；
- 多项功能共用完整 `{PID, creation time}` 进程身份和独占所有权，启用前校验版本、签名与原字节，停用后回读恢复结果。

## 界面与窗口修复

- 首页重新压缩分组间距，常见全屏比例不再在中段或底部留下无意义的大块空白；
- 记忆的窗口尺寸会按当前显示器和 DPI 限制在可见区域内，并在启动时居中，不再恢复到屏幕外；
- 坐标尚未读取时使用紧凑空状态，不再撑出整块空白；
- `960×640` 下连接与紧急停止按钮保持同一行，虚拟地面入口能在首屏看到；页面本身没有横向溢出，只有顶部功能标签按设计独立横向滚动。

## 仍需说明的边界

- 第六条及以后武器技能是运行时附加，不是把存档武器记录扩成无限物理槽；
- 空中动作实验不是稳定的地面动作替代，本版推荐使用虚拟地面；
- 任务奖励倍率当前仍只证明修改本机结算，尚未证明能把额外奖励同步并永久保存到未安装工具的 PC 或 PlayStation 队友；
- 人物动作速度的本机/全队范围尚未完成任务验收，因此不在本版正式可用功能中宣传。
