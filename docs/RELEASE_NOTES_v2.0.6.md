# v2.0.6｜恢复已实现实验功能的正常入口

这一版修正部分功能已经实现、也已完成版本与恢复链路适配，却仍被旧文案或旧 UI 门禁标成“仅预览/恢复”的问题。维护端无法覆盖所有角色、任务和切场景组合，不再成为锁住现有功能的理由；这些入口保持“实验”标识，由用户在备份后按实际玩法验收。

## 功能入口修正

- 天然掉落与锻造、角色语音、城镇镜头和虚拟因子统一显示为游戏 2.0.2 / 2.0.3 可用实验功能；
- 虚拟因子不再错误显示为“稳定版仅预览/恢复”，可以正常开启 1 至 8 个额外运行时槽；
- 坐标与移动工具不再被概括为只读预览，世界轴移动、游戏内方向键和重力抑制均按实际能力展示；
- 重力抑制恢复“抑制重力”按钮，连接受支持游戏后可以开启，启用后可随时恢复原始指令；
- 镜头页的版本提示同步为 2.0.2 / 2.0.3，避免用户误以为 2.0.3 无法使用。

## 仍然保留的保护

- 所有运行时写入继续校验游戏版本、完整进程身份、唯一特征码和原字节；
- 重力抑制继续使用独立 lease、写后回读和恢复路径；
- 虚拟因子继续核对真实未装备实例，同一 SlotID 不允许重复占用，也不会扩写存档的 12 个物理槽；
- 天然掉落部署继续使用内置锁定表、事务日志、备份、原子替换和冲突拒绝；
- F12、显式停用、断开和应用退出继续恢复本工具管理的运行时状态。

## 当前能力说明

天然掉落与锻造部署、虚拟因子、音频、城镇镜头、世界轴移动和重力抑制均已实现并保留入口。跨角色、跨场景和多 Hook 组合继续作为用户实机反馈范围，不会仅因维护端无法遍历所有玩法而被锁定。

当前会话伤害已经记录原始来源实例、动作编号、伤害上限和上限前伤害，战斗目录也包含角色上限表；稳定的玩家、队友、宠物、召唤物身份映射，以及全角色逐动作最终精确上限，不在当前实现范围内。noclip 与相机相对飞行也没有可执行入口；现有空间能力是世界轴移动、游戏内方向键和独立重力抑制。
