# v2.0.4｜适配游戏 2.0.3，实时功能安全分流

游戏更新到 2.0.3 后，这一版先解决最重要的问题：哪些功能可以继续使用，哪些必须等重新验收。

## 可以继续使用

- 存档解析、备份、原子写入和写后回读；
- 角色配装编辑、按技能目标配装和角色参考路线；
- 因子、祝福、召唤石、武器、伤害上限和成长目录；
- 配装 JSON、短码、二维码图片导入、在线图鉴和分享图；
- Relink Logs JSON、数据库与本地战斗档案；
- 不依赖游戏进程的其他离线查看与整理功能。

我们重新解包了游戏 2.0.3。项目使用的因子、祝福、召唤石、掉落、武器、伤害上限、成长、专精和无尽规则表均与 2.0.2 逐字节一致，332 份角色与战斗配置也没有变化。本次游戏更新发现的表级变化仅涉及葡萄牙语、英语和韩语的本地化文本。

## 2.0.3 上暂时锁定的功能

游戏 EXE 已经变化，运行时地址也整体迁移。以下功能不会拿 2.0.2 的旧地址在 2.0.3 上尝试写入：

- 游戏内因子、祝福石、召唤石和上限突破即时编辑；
- 队友配装进程采集、选中物品和角色公式进程采样；
- 战斗、角色、任务和怪物运行时补丁；
- 显示与房间、音频、城镇镜头、空间移动和虚拟因子运行时；
- 天然掉落与锻造的 `data.i` 部署。

这些入口仍保留给已经验证的游戏 2.0.2。检测到游戏 2.0.3 时，应用会在共享进程连接入口直接说明兼容边界，并在保存进程句柄或模块地址之前停止，不会连接成功后再执行旧逻辑。

天然掉落使用的目标表虽然没有变化，但新版归档生成、游戏实际加载和完整恢复还没有完成现场闭环，因此同样暂不对 2.0.3 开放。

## 版本页面更清楚

“版本适配”页现在分开显示：

- 游戏 2.0.3 静态数据核对结果；
- 2.0.3 已支持的离线与分享流程；
- 2.0.3 暂停的实时功能和 `data.i` 部署；
- 历史 2.0.2 运行时证据和仍未完成的实机边界。

标题栏和应用版本也已更新为游戏 2.0.3 / 工具 v2.0.4，避免把游戏版本和工具版本混为一谈。

## 仍需后续验收

- 用游戏 2.0.3 实际保存过的复制存档完成游戏内重启回读；
- 为每条运行时路径重新建立地址、原字节、写后回读和恢复证据；
- 对原生 Hook 完成切角色、切场景和多 Hook 长时测试；
- 完成新版 `data.i` 隔离部署、游戏加载和恢复测试；
- 核对本次变化的路西法英文语音事件与实际听感。

自动化测试和静态表一致只能证明对应的软件合同，不能替代这些真实游戏验收。

## 升级建议

1. 退出旧版工具，下载 v2.0.4 的版本化 EXE 或 ZIP；
2. 重要存档先自行复制一份；
3. 游戏 2.0.3 可以正常使用离线存档、配装、分享和 Logs；
4. 遇到实时功能的 2.0.3 提示时不要反复重试，等待后续重新验收版本。
