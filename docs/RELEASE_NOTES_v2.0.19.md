# v2.0.19｜武器技能即时编辑修复

- 修复武器技能即时编辑在连接后可能读取错误版本地址、提示“武器焦点指令字节异常”的问题。
- 现在会先校验实际游戏 EXE，再选择对应版本的武器入口，不会把未初始化的版本状态误当成游戏 2.0.3。
- 固定地址发生变化时，会使用完整 23 字节特征自动寻找唯一武器焦点入口；找不到或存在多个结果时仍会停止，避免写错位置。
- 武器保存函数改为复用因子与祝福已经使用的版本化地址和唯一特征回退流程。
- 已在游戏 2.0.5 实际进程完成武器入口读取、捕获 Hook 启用、所有权回读、停用和原指令恢复测试。

如果此前遇到 Issue #22 的报错，请更新到本版本后重新连接游戏并点击“启用读取”。
