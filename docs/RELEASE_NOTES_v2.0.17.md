# v2.0.17｜资源编辑与战斗规则修复

本次更新集中修复游戏 2.0.4 下的资源编辑和怪物规则功能：

- 修正药水编辑在游戏 2.0.4 中使用的运行时地址。货币与药水继续使用各自的数量范围，未进入相应游戏场景时不会把无效内存当成药水数量写入。
- 将极沌空域 CP 从 RP 中独立出来。进入并初始化极沌空域后，可以单独读取和修改 CP，不会再误改 RP。
- 修正 Io Focus 异常额外伤害倍率的计算，避免特殊伤害路径使用错误差值。
- 补齐部分首领使用的第二条 OD 槽倍率路径，使 OD 槽倍率在不同首领结算路径下保持一致。
- 加强上述运行时补丁的版本识别、原字节校验、写后回读与关闭恢复，降低游戏更新或场景切换时误写的风险。

本版已完成游戏 2.0.4 的自动化回归和 Windows 生产构建。欢迎实际使用并通过 GitHub Issue 反馈具体页面、操作步骤与游戏场景。
