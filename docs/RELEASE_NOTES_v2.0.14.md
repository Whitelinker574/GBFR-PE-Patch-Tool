# v2.0.14｜货币、药水校验与任务专属因子修复

这次修复两处会直接影响实际操作的问题：

- 修正实时货币编辑和副本药水的数值范围写反。金币、MSP、高级炼成点数和共鸣点数现在可正常填写到 `2147483647`；复活药与群疗药保持 `0–999`，报错也会准确指出当前正在编辑的项目。
- 加入罗兰任务奖励的真实专属因子 `万能药+`：固定为“万能药 Lv15 + 追击 Lv15”。它会同时出现在离线因子生成、游戏内即时编辑和配装编辑使用的共享目录中，不再只能识别名称却无法选择或生成。
- 这条任务专属记录与普通随机副词条词池分开保存；固定组合会显示为合法，手动改成其他可编码副词条时仍会明确提示并允许用户确认写入。

离线写入继续执行自动备份、原子替换和重新打开回读。实时编辑请先连接正确的游戏进程，并在对应资源已经出现在游戏界面后再读取和写入。
