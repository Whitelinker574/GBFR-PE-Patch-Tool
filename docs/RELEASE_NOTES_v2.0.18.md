# v2.0.18｜游戏 2.0.5 全面适配

本次更新完成《碧蓝幻想：Relink》Ver. 2.0.5 的游戏文件、数据表和运行时功能迁移：

- 重新识别 2.0.5 游戏程序，并逐项迁移配装检测、因子与祝福读取、武器即时编辑、召唤石、坐标移动、任务规则、怪物倍率、OD、镜头、音频、虚拟因子和显示便利功能。
- 重新解包全部 2,120 份 `system/table` 文件。2.0.5 只修改任务奖励和菲迪埃尔动作参数两张表；因子、祝福、召唤石、武器、物品和图标目录保持原有真值。
- 将 MSP 的自然上限更新为 `9,999,999`。任务奖励倍率会基于 2.0.5 提高后的官方奖励数量继续计算。
- 修复 2.0.5 队友配装句柄布局。真实游戏进程已成功读取当前角色的武器、完整配装和 12 颗因子。
- 修复材料与物品数量、11 条免费消费路径、普通与巴布类首领 OD、召唤持续时间、连续跳跃及 QOL 编队入口在 2.0.5 中的位置变化。
- 游戏 2.0.5 不再使用未经验证的副本药水直写链；需要持续使用药水时，可开启“免费制作、交易与升级”。旧版药水编辑仍按原有版本化地址使用。
- 掉落与锻造功能继续内置所需的 11 张原表；这些表在 2.0.5 中逐字节不变，并已加入新版 EXE 与 `data.i` 身份校验、事务备份和恢复流程。

2.0.5 适配已经完成，欢迎大家使用并通过 GitHub Issue 反馈具体页面、操作步骤与游戏场景。
