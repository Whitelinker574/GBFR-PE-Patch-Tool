# v2.0.16｜游戏 2.0.4 适配

本次版本完成《碧蓝幻想：Relink》游戏 Ver. 2.0.4 适配：

- 更新 2.0.4 游戏身份识别和运行时布局。连接游戏后，工具会按 2.0.4 的实际 EXE 选择地址、原字节与 Hook，不会把旧版本地址直接套到新版本。
- 重新核对内置运行时功能，包括武器即时编辑、怪物与战斗规则、任务奖励倍率、免费制作与升级、召唤持续时间、虚拟因子、坐标与移动、镜头、音频、显示和房间工具等。
- 修正极沌空域快速等待在 2.0.4 中使用的计时器地址，并重新确认任务结算奖励倍率入口。
- 游戏 2.0.4 的 `data.i` 与 2.0.3 完全一致，因此因子、祝福、召唤石、物品、掉落和配装目录继续使用原有完整数据，不需要用户重新寻找或导入表文件。
- 同步更新应用内的版本提示、兼容说明和错误信息，未知游戏版本仍会给出清楚的提示。

2.0.4 适配已经完成，欢迎大家实际使用；遇到 Bug 时请在 GitHub Issue 中说明使用的页面、操作步骤和游戏场景，方便继续修正。
