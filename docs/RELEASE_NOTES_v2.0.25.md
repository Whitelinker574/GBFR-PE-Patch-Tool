# v2.0.25｜修复验证游戏文件后掉落部署卡住

- 修复天然掉落修改的一处状态识别问题：Steam 验证或外部恢复将 `data.i` 精确还原为部署前内容，但本工具的清单、备份和生成表仍在时，现在可以安全地重新部署或恢复原始掉落。
- 只接受清单记录的原始索引或部署后索引；继续校验原始备份的 SHA-256、索引结构和游戏标识，以及每个生成表的哈希。未知索引、缺失或被改动的生成表、异常备份仍会拒绝覆盖。
- 索引不匹配时显示当前、原始和部署后三个 SHA-256，便于排查游戏更新、其他 Mod 或旧部署状态。
- 新增 16 个状态回归场景和 2 个事务回滚用例，保留现有备份、快照、失败回滚和完整性保护。

兼容游戏 2.0.6。本次发布通过 Windows 自动构建和测试；未进行游戏内实机验证。Issue #30 报告者的具体本地原因仍待文件哈希确认。

更新前请退出游戏、Mod 管理器和旧版工具，然后使用新版程序。若索引已恢复且原始备份、生成表均完整，可直接重试“生成并部署”或“恢复原始掉落”，无需删除游戏文件、修改清单哈希或关闭校验。若仍报索引不匹配，请保留现有文件并在 [Issue #30](https://github.com/Whitelinker574/GBFR-PE-Patch-Tool/issues/30) 提供错误中的哈希和工具版本。
