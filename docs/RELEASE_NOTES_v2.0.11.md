# v2.0.11｜修复外部存档配装武器归属

这一版修复部分外部、迁移或记录不完整的存档在“配装预设”中无法使用角色专属武器的问题。

## 修复内容

- 页面已经选中明确角色时，直接从该角色的官方身份 hash 自动补全对应 `PLxxxx` 归属，不再只依赖存档里可能缺失的专精节点和当前武器引用；
- 覆盖全部 29 名可玩角色，包括菲迪埃尔等 DLC 角色；
- 缺少专精记录、当前武器引用悬空或旧工具导入不完整时，合法专武仍可正常预览、编辑和写入；
- 未知角色仍保持保守拒绝，真正属于其他角色的专武仍不能误装；
- 同一套归属解析同时用于配装预览、编辑上下文和写入前校验，不会只修界面而漏掉实际写入。

## 触发条件

旧版本会在角色配装记录同时缺少“可识别专精节点”和“可解析的已装备武器引用”时返回空归属。常见于外部导入、旧版转换、配装记录被部分清理，或武器 SlotID 引用已经失效的存档。角色本身并没有损坏，旧提示把“辅助证据缺失”误判成了“角色身份未知”。
