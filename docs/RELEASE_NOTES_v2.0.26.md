# v2.0.26 · 角色强化重置与运行时修复

适用游戏版本：**2.0.6**。

- 新增 **角色强化重置**：打开“存档对比与复制 → 角色强化重置”，选择存档和角色后，可以全部取消学习，或恢复入队时自动解锁的强化。只处理选定角色；自动备份，写入后重新读取核对。
- 重置保留角色等级、装备和其他角色，不返还 MSP。取消强化也会取消对应的属性、技能和因子栏位，现有配装可能需要重新整理；撤销操作请恢复自动备份。
- 全部取消学习后，配装属性预览同步清除强化加成，不会因旧进度标量仍在而显示满强化属性。
- 修复城镇中奥义槽尚未初始化时，坐标工具和队伍快照读取一起失败的问题；此时奥义槽显示为未记录，不再影响其他有效数据。
- 修复游戏 2.0.6 下连续跳跃因旧版指令校验而无法开启的问题，保留关闭时恢复原字节的处理。
- 修复窗口顶部一直显示旧版本号的问题，现在与应用实际版本保持一致。
- 加强称号数据的异常长度校验，并补齐真实存档副本相关回归测试。
- 补齐极星双 Boss 使用的额外血量与 OD 路径，直接跟随现有倍率控件，不用额外开启另一组选项。
- 修复多入口怪物补丁在辅助 Hook 尚未完成时，过早报告部署完成的问题；关闭及异常恢复会一并处理这些入口。

感谢 Issue #26 提供真实存档样本。欢迎继续反馈使用中遇到的问题，附上游戏版本、工具版本和具体操作步骤会更方便定位。
