# v2.0.27 · 修复游戏更新后掉落规则无法部署

适用游戏版本：**2.0.6**。

- 修复游戏更新后，旧版掉落部署清单和备份仍留在目录里，导致“生成并部署”和“恢复原始掉落”都无法使用的问题。
- 检测到已核对的新版原始游戏文件时，自动保留旧文件，再按当前版本重新部署；选择恢复原始掉落时，也不会把旧版索引写回新版游戏。
- 旧备份、部署清单和生成表保留在游戏目录的 `data.i.gbfr-codex-natural-drop.history` 文件夹。部署完成后会显示具体位置。
- 增加“游戏已更新，可迁移旧部署”的提示；未知或被其他 Mod 改动的文件仍会说明原因并保留，不会直接覆盖。

感谢 Issue #30 提供完整校验信息，帮助定位跨版本残留问题。
