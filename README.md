# 碧蓝幻想：Relink 空域工坊（Relink Skyfarer Workshop）

[English README](README_EN.md) · [下载最新正式版](https://github.com/Whitelinker574/GBFR-PE-Patch-Tool/releases/latest) · [在线配装图鉴](https://share.whitelinker.top)

面向《Granblue Fantasy: Relink》DLC 2.0.3 的 Windows 存档、配装与分享工具，并保留经过验证的 2.0.2 单机运行时能力。项目前身为 GBFR PE Patch Tool，v2.0.12 起更名为「碧蓝幻想：Relink 空域工坊」。

## 快速开始

1. 从 [GitHub Releases](https://github.com/Whitelinker574/GBFR-PE-Patch-Tool/releases/latest) 下载 `windows-amd64.exe` 或 ZIP，解压后运行；
2. 第一次使用先进入「存档与配装」，确认工具识别到正确的 `SaveData` 槽位；
3. 离线编辑前退出游戏，完成预览后再确认写入；
4. 实时功能先启动游戏，再在对应页面点击连接；用完点「停止/恢复」；
5. 启动失败查看 `%LOCALAPPDATA%\GBFR-PE-Patch-Tool\startup.log`。

默认存档目录：

```text
C:\Users\<用户名>\AppData\Local\GBFR\Saved\SaveGames\
```

## 功能总览（五个工作区）

### 1. 存档与配装（离线写入）

完全退出游戏后使用。写入统一经过：自动备份 → 临时文件修改 → 校验和修复 → 原子替换 → 重新打开并逐字段回读。

| 页面 | 功能 |
| --- | --- |
| 配装预设 | 查看、编辑、导入完整配装（角色、武器与技能、12 因子、祝福、召唤石、专精、上限突破、角色强化）；智能配装按技能目标自动选因子，12 槽缺口明确提示，制造缺口确认后才创建 |
| 因子修改 | 生成、批量管理与删除存档因子；配置等级与主/副特性；组合检查只提示不拦截 |
| 祝福修改 | 生成祝福并设置三条词条，支持队列批量生成 |
| 召唤石（存档） | 新增或修改召唤石的种类、加护、词条、等级与状态；换种类自动迁移已装备引用 |
| 物品与武器 | 修改物品、素材、养成资源、武器等级；支持武器觉醒与超越阶段同步 |
| 角色使用次数 | 查看并批量修改所选角色的使用次数 |
| 任务与称号 | 修改任务完成次数、称号解锁与已查看状态；称号奖励领取记录保持不变 |
| 存档对比与复制 | 并排比较两份存档差异，按角色成长/配装/物品/任务状态/未知结构分类；已确认语义一致的记录可左右互写，未知结构不复制 |

### 2. 游戏内即时编辑（实时写入）

先启动游戏进入存档，再从页面连接游戏进程。每次写入绑定当前进程与选中目标，写后回读；重新进档、重启游戏或列表刷新后需重新连接或重新选中目标。

| 页面 | 功能 |
| --- | --- |
| 因子即时编辑 | 修改游戏中当前选中的因子（等级、主/副特性） |
| 祝福石即时编辑 | 一次事务写入当前祝福石的三条词条 |
| 武器技能即时编辑 | 备份、修改并回读五个永久技能槽；经游戏原生聚合路径常驻追加第六技能 |
| 召唤石即时编辑 | 修改背包中召唤石的因子、副参数与阶级，写入后调用游戏保存函数持久化 |
| 角色上限突破 | 读取并修改突破结果界面的四个能力槽 |
| 货币素材与任务掉落 | 修改金币、药水、素材消耗与任务掉落等运行时数据 |

### 3. 配装采集与复刻（只读监测 + 实时录制）

| 页面 | 功能 |
| --- | --- |
| 队友配装持续检测 | 后台持续连接，三次稳定快照后按场次归档；支持导入 Relink Logs JSON / `logs.db`；浏览战斗档案、队伍伤害、技能明细与配装快照；缺失范围显示「未记录」，不拿其他角色数据补齐 |
| 十二因子实时录制/复刻 | 记录当前 12 个因子并导出为 JSON，或逐项复刻到备用因子；分享入口可生成短码/二维码/分享图 |

### 4. 单机运行时工具（仅单机/主机端）

只面向单机环境；开启后状态显示在顶部状态栏，切换页面不中断，F12 或页面停用统一恢复。

| 页面 | 功能 |
| --- | --- |
| 显示与房间 | 画面、房间号、队长、坐标等运行时信息 |
| 虚拟因子槽 | 常驻附加虚拟因子，切换页面不停止 |
| 角色语音混音台 | 调整角色语音 |
| 城镇镜头工坊 | 五档镜头预设（细节 / 默认 / 舒适 / 战斗广角 / 远景） |
| 坐标移动 | 虚拟地面移动：WASD 水平移动、PageUp/PageDown 升降；重力抑制 |
| 战斗 / 角色 / 任务补丁 | 闪避、格挡、Link、召唤限制、部位破坏、任务倒计时、任务分数、支线目标、召唤持续时间、免费制作/交易/升级、冷却与蓄力等 60 项运行时补丁；任务结算普通物品奖励倍率 1×~16× |
| 怪物倍率 | 怪物血量、伤害、昏厥条与 Overdrive 状态（实验功能） |
| 无尽之塔 | 无尽模式计时与规则（只读参考） |

### 5. 游戏文件、诊断与设置

| 页面 | 功能 |
| --- | --- |
| 掉落与锻造规则 | 天然掉落与锻造：任务普通物品奖励倍率（1×~16×）与无尽模式锻造师奖励物品池（1–999 基础数量）两条独立路径，互不叠乘；`data.i` 部署始终提供备份恢复 |
| 选中物品只读 | 查看当前选中物品/关键物品信息，不写入 |
| 角色公式采样 | 只读读取最终 HP、攻击力、暴击率、昏厥值，A/B/A/B 严格实验与脱敏证据包导出；不写进程或存档 |
| 版本适配 | 按功能显示 2.0.3 适配状态；未适配功能明确标识 |
| 游戏文件维护 | Steam 路径自动识别、游戏 EXE `.bak` 备份与恢复 |
| 语言与设置 | 中/英界面切换，本机保存 |

## 安全与数据边界

- **写前备份、写后回读**是统一规则：离线写入自动创建可恢复备份并逐字段回读；实时写入绑定 `{PID, 创建时间}`，启用前校验 EXE 身份与原字节，停用/断开/退出时恢复
- **合法性分级**：每项修改按「合法 / 强制 / 未知 / 不可写」四态标注；超出已验证游戏规则的组合明确拒绝写入，需强制写入的条目先警告再执行，不会静默覆盖你的存档
- **不冒充数据**：界面不会把全局事件冒充个人 DPS，也不会把表内基线冒充最终动作值；未获得实机证据的数值标为估算、候选或验证中
- **实验边界**：天然掉落、虚拟因子、镜头、坐标移动、重力抑制等保留「实验」标识；当前会话伤害的身份映射与每动作最终精确上限尚未覆盖；noclip 与相机相对飞行无入口
- **离线/实时/只读**三种工作流严格区分：离线写存档文件、实时写进程内存、只读不改任何数据

## 在线配装分享

- 相同配装正文生成稳定短码（16–24 位），服务端对相同配装帧去重；支持二维码分享图本地识别导入（图片不上传）
- 公开图鉴支持按角色/武器/因子/祝福/召唤石/专精/技能搜索，按最新/名称/点赞排序，可点赞、可评论
- 分享图工坊：横版 1920×1080、竖版 1440×1920、方形 1600×1600，下载 PNG 保持真实像素
- 可关闭公开上传，离线长码/JSON 文件兜底

## 故障排查

| 现象 | 先做什么 |
| --- | --- |
| 没找到存档 | 检查默认目录，或用「浏览…」手动选择 `SaveData*.dat` |
| 显示多个存档不知选哪个 | 逐个选择，根据页面读出的角色/配装/记录确认目标 |
| 实时页面显示未连接 | 确认游戏已启动并进入存档，在当前页面重新连接 |
| 提示目标失效 | 回到游戏重新选中目标，返回工具刷新后再写入 |
| 版本或 EXE 未识别 | 停止应用文件补丁，到「版本适配」查看各功能状态，必要时用 Steam 验证文件 |
| 写入后结果不对 | 停止写入并完全退出游戏；用写入前的备份恢复点还原 |
